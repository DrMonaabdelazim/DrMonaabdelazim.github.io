# Mona Abdelazim — AcademicPages website

This starter adapts the AcademicPages / Minimal Mistakes-style personal website structure to Mona Abdelazim's profile.

## Setup
1. Create a repository named `DrMonaabdelazim.github.io`.
2. Upload these files to the repository root.
3. In Settings → Pages, configure deployment from the branch/root if needed.
4. Review `_config.yml` and add your photo and email if desired.

The site uses the AcademicPages remote theme and the profile content in `index.md`.
