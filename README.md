# Mona Abdelazim Personal Portfolio

Static, responsive portfolio site for NLP, Arabic AI, speech technologies and applied research.

## Files
- `index.html`: homepage
- `style.css`: site styles
- `assets/network.svg`: hero visual
- `projects/`: four project case-study pages

## Preview locally
Open `index.html` in a browser.

## Publish via GitHub Pages
1. Create a repository named `DrMonaabdelazim.github.io`.
2. Upload the files and folders in this package to the repository root.
3. Open Settings → Pages.
4. Select Deploy from a branch, `main`, folder `/root`.
5. Save. The site should be published at `https://DrMonaabdelazim.github.io`.

## Before publishing
- Replace `YOUR_EMAIL` in `index.html`.
- Add real repository, demo and publication links.
- Verify role descriptions and dates.
- Add only approved public details about Robot Shams and research datasets.
- Optionally add a portrait, CV PDF and complete publication list.


## Brand palette
Dark navy charcoal background, warm cream text, soft gold highlights, dusty rose details and sage green secondary accents.
